# ABX

[English](README.md) | **Русский**

ABX (Agent Box) запускает консольных агентов для работы с кодом внутри песочниц Bubblewrap на Linux. Каждый профиль — это постоянный приватный home агента или набора связанных инструментов: исполняемые файлы, настройки, кэши и авторизация сохраняются между запусками.

При запуске агента текущий проект подключается с записью как `/workspace`. Профиль доступен с записью как `/home/agent`; выбранные системные файлы доступны только для чтения; временные каталоги, процессы и устройства имеют отдельные представления внутри песочницы. Сеть общая с хостом. Точные границы описаны в [модели защиты](docs/ru/security.md).

## Требования

- Linux с ядром **6.5 или новее**. Shared skills дополнительно используют `openat2`, доступный с Linux 5.6. Готовый опубликованный бинарник предназначен для x86-64 (`amd64`).
- Запускайте ABX обычным пользователем, без `sudo`.
- Bubblewrap **0.12.0 или новее** по пути `/usr/bin/bwrap`, принадлежащий root. Бинарный
  файл должен быть обычным файлом, недоступным для записи group/other и без
  setuid, setgid и sticky-битов.
- Хост должен разрешать непривилегированные user namespaces.
- Локальная запись `/etc/passwd` для вашего UID с корректным домашним каталогом и пригодным login shell.
- Среда выполнения или менеджер пакетов, который нужен выбранному агенту, например Bun или npm.

## Установка

Скачайте архив нужной версии со [страницы релизов](https://github.com/kydex/abx/releases):

```text
abx-X.Y.Z-linux-amd64.tar.gz
```

Распакуйте его и установите бинарник:

```sh
abx_version=X.Y.Z
tar -xzf "abx-$abx_version-linux-amd64.tar.gz"
cd "abx-$abx_version-linux-amd64"
mkdir -p "$HOME/.local/bin"
install -m 755 ./abx "$HOME/.local/bin/abx"
abx version
```

Показанная версия должна совпадать со скачанной. Убедитесь, что `$HOME/.local/bin` входит в PATH вашей оболочки.

Если вы скачали и файл `abx-X.Y.Z-SHA256SUMS`, архив можно проверить до распаковки:

```sh
abx_version=X.Y.Z
sha256sum --check --ignore-missing "abx-$abx_version-SHA256SUMS"
```

Если хотите собрать ABX самостоятельно, см. [Установку](docs/ru/installation.md#сборка-из-исходников).

## Быстрый старт

Создайте профиль. Имя профиля должно совпадать с исполняемым файлом, который будет запускать `run`:

```sh
abx profile create opencode
abx shell opencode
```

Теперь вы внутри песочницы профиля с `HOME=/home/agent`. Например, установите OpenCode через Bun:

```sh
bun add -g opencode-ai
opencode --version
exit
```

Перейдите во внешнем терминале в каталог проекта и запустите агента:

```sh
cd "$HOME/code/my-project"
abx verify opencode
abx run opencode
```

`verify` необязателен, но полезен после установки или изменений на хосте. Он запускает настоящую тестовую песочницу и проверяет основные свойства изоляции; установленный исполняемый файл агента для этого не нужен.

В одном профиле можно держать [Herdr](https://herdr.dev/) и несколько agent CLI, а `work` сохраняет песочницу живой, когда клиент от неё отсоединяется. Полный разбор, включая detach и повторное подключение, — в [Профиль с несколькими агентами: Herdr](docs/ru/usage.md#профиль-с-несколькими-агентами-herdr).

## Команды

| Команда | Назначение |
|---|---|
| `abx profile create <profile>` | Создать пустой постоянный профиль |
| `abx profile show <profile>` | Показать путь профиля, состояние основного исполняемого файла и shared skills |
| `abx profile list` | Показать список профилей |
| `abx shell <profile>` | Открыть login shell профиля без подключения проекта |
| `abx work <profile>` | Открыть login shell с текущим проектом в `/workspace`; одноимённый executable не требуется |
| `abx run <profile> [-- <argument>...]` | Запустить одноимённый основной исполняемый файл профиля с текущим каталогом как `/workspace` |
| `abx inspect <profile>` | Показать план `run` без запуска Bubblewrap; требуется одноимённый executable профиля |
| `abx verify <profile>` | Запустить тестовую песочницу и проверить основные свойства изоляции |
| `abx help`, `-h`, `--help` | Показать справку CLI |
| `abx version`, `-v`, `--version` | Показать версию ABX |

По умолчанию профили находятся в `.local/share/abx/profiles` в домашнем каталоге из `/etc/passwd` (не `$HOME`). Абсолютный `XDG_DATA_HOME` меняет базовый каталог хранения. Точный путь профиля можно посмотреть через `abx profile show <profile>`.
