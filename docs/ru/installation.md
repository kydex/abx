# Установка и обновление

[English](../installation.md) | **Русский**

Все команды выполняйте во внешнем терминале от обычного пользователя. Не устанавливайте и не запускайте ABX через `sudo`.

## Требования к системе

ABX требует:

- Linux;
- Bubblewrap **0.12.0 или новее** по пути `/usr/bin/bwrap`;
- разрешённые хостом непривилегированные user namespaces;
- локальную запись `/etc/passwd` для UID запускающего пользователя;
- существующий абсолютный домашний каталог и пригодный login shell из этой записи passwd.

Опубликованный готовый бинарник предназначен для `linux/amd64` (`x86_64`). Для других архитектур Linux ABX можно собрать из исходников, если их поддерживают Go и используемые зависимости.

Базовая проверка:

```sh
uname -m
id -u
/usr/bin/bwrap --version
awk -F: -v uid="$(id -u)" '$3 == uid { print; found = 1 } END { exit !found }' /etc/passwd
```

`id -u` не должен выводить `0`. ABX использует фиксированный путь `/usr/bin/bwrap`; другой `bwrap`, найденный раньше в PATH, на это не влияет.

Login shell из `/etc/passwd` должен существовать, быть исполняемым и находиться в системных каталогах, которые ABX делает видимыми. Обычные системно установленные `/bin/bash` и `/usr/bin/fish` подходят.

## Установка готового бинарника

Скачайте опубликованные файлы нужной версии:

```text
abx-X.Y.Z-linux-amd64.tar.gz
abx-X.Y.Z-SHA256SUMS
```

Архив и файл контрольных сумм должны относиться к одной версии. Перед распаковкой проверьте файл:

```sh
abx_version=X.Y.Z
sha256sum --check --ignore-missing "abx-$abx_version-SHA256SUMS"
```

Продолжайте только если для бинарного архива показано `OK` и команда завершилась успешно.

Установите программу в пользовательский каталог бинарников:

```sh
tar -xzf "abx-$abx_version-linux-amd64.tar.gz"
mkdir -p "$HOME/.local/bin"
install -m 755 "abx-$abx_version-linux-amd64/abx" "$HOME/.local/bin/abx"
export PATH="$HOME/.local/bin:$PATH"
command -v abx
abx version
```

Версия из `abx version` должна совпадать со скачанной. `export` действует только в текущей оболочке; при необходимости добавьте `$HOME/.local/bin` в настройки PATH своей оболочки.

Установка бинарника ABX не создаёт профили. При замене бинарника существующие данные профилей не изменяются.

## Сборка из исходников

Для сборки нужна версия Go, указанная в `go.mod`, и доступ к Go-зависимостям проекта. Make удобен, но не обязателен.

Из архива исходников:

```sh
abx_version=X.Y.Z
tar -xzf "abx-$abx_version-source.tar.gz"
cd "abx-$abx_version-source"
make build
```

`make build` создаёт `./abx` для текущей платформы с `CGO_ENABLED=0`.

Без Make выполните эквивалентную команду:

```sh
env CGO_ENABLED=0 go build -trimpath -buildvcs=false -o abx ./cmd/abx
```

Установите результат:

```sh
mkdir -p "$HOME/.local/bin"
install -m 755 abx "$HOME/.local/bin/abx"
export PATH="$HOME/.local/bin:$PATH"
abx version
```

Если вместе с архивом исходников вы получили `abx-X.Y.Z-SHA256SUMS`, проверьте архив до распаковки так же, как готовый бинарник.

`make check`, `make live` и `scripts/package.sh` относятся к разработке и выпуску проекта; для установки и обычного использования ABX они не нужны. Если вы работаете над кодом, см. [Разработку](development.md).

## Первый запуск

Создайте профиль и откройте его shell:

```sh
abx profile create opencode
abx shell opencode
```

Установите агента внутри этой оболочки и выйдите через `exit`. Примеры для Bun и npm есть в [Использовании](usage.md).

Из каталога проекта во внешнем терминале:

```sh
abx verify opencode
abx run opencode
```

## Обновление ABX

Закройте активные сессии ABX, установите новый бинарник поверх старого и проверьте:

```sh
command -v abx
abx version
```

Обновление ABX заменяет только бинарник программы. Профили, установленные агенты, настройки и сохранённая в профилях авторизация остаются на месте. Перед обновлением при необходимости прочитайте [CHANGELOG.md](../../CHANGELOG.md).

Агент обновляется отдельно от ABX — внутри соответствующей оболочки профиля.

## Удаление ABX

Для стандартного пути установки:

```sh
rm -i "$HOME/.local/bin/abx"
```

Команда удаляет только бинарник ABX. Профили и shared skills остаются на диске.

Если нужен точный путь профиля, до удаления ABX выполните `abx profile show <name>`. Ручное удаление каталога профиля удаляет установленные в нём программы, настройки, кэши и сохранённую авторизацию. Автоматической команды удаления профиля в ABX нет.

Не удаляйте целиком `XDG_DATA_HOME`: там могут находиться данные других приложений.
